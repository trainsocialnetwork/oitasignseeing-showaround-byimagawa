# 大分たびヒアリング

大分に遊びに来る人向けのヒアリングフォーム。

- 全15問（旅のスタイル・行きたい場所・食の好み・宿への希望など）をぽちぽち答える
- 最後に「質問と回答」だけのテキストを自動コピー → LINEに貼って送ってもらう
- もらった回答をもとに、こちらで宿・観光地のおすすめを考える

## 公開ページ

https://trainsocialnetwork.github.io/oitasignseeing-showaround-byimagawa/
